# 方法说明

两条主线：**ECM 参数辨识**回答「电池为什么变差」，**RUL 建模**回答「还能跑多久」。

---

## 一、ECM：Thevenin 一阶等效电路

### 1.1 模型

恒流放电时端电压：

$$V_t(t) = \mathrm{OCV}(\mathrm{SOC}) - I\,R_0 - I\,R_1\left(1 - e^{-t/\tau_1}\right),\qquad \tau_1 = R_1 C_1$$

- `OCV(SOC)`：开路电压，SOC 的函数
- `R0`：欧姆内阻（电解液、集流体、接触电阻）
- `R1 / C1`：电荷转移与双电层极化（时间常数 τ₁）

### 1.2 辨识流程（`scripts/phase_a2_ecm.py`）

**① OCV(SOC)：20 圈充放电平均 + PCHIP**

单用放电曲线会把极化压降混进 OCV。做法是把前 20 圈充电、放电电压都按 SOC 分箱（100 箱）取平均，对称的极化滞回相互抵消；再用 PCHIP 单调插值平滑，避免样条过冲。

**② OCV 偏置标定**

充放电平均法在低 SOC 段仍有系统偏差。用训练圈残差拟合三阶多项式 δ(SOC)，把它作为 OCV 的修正项。这一步把 B0005 的复测 RMSE 从 2.25% 压到 1.72%。

**③ R0：电流阶跃**

放电起始 0 → 2 A 的瞬时压降 ΔV/ΔI。时间尺度毫秒级，几乎不受 OCV 估计误差影响，是整条链路里物理意义最明确、最不容易被污染的量。

**④ R_dc(SOC)：恒流区逐点求总内阻**

$$R_{dc}(\mathrm{SOC}) = \frac{\mathrm{OCV}(\mathrm{SOC}) - V_t(\mathrm{SOC})}{I}$$

按 SOC 分箱后，减去 R0 即得极化分量 `R_pol = R_dc − R0`。

**⑤ 验证口径**

第 1 次放电辨识参数，第 3 次放电（同工况）复测，计算端电压 RMSE，分母取实测量程（`max(V) − min(V)`），即「相对量程百分比」。

### 1.3 可辨识性边界（重要）

NASA 是恒流放电，不是 HPPC 脉冲。一次电流阶跃下：

- 极化电压约 40 mV
- 小于 OCV 的估计不确定度

因此 **R1/C1、R2/C2 的 SOC 依赖不可单独辨识**。强行上二阶模型会让 R2 撞上参数上界（拟合看似变好，参数已无物理意义）。这是数据决定的，不是模型缺陷——本项目选择「只报可辨识的量」，而不是堆参数。

## 二、ΔQ(V)：两种定义，别混用

### 2.1 论文口径（RUL 主线使用）

$$\Delta Q(V) = Q_{100}(V) - Q_{10}(V)$$

跨循环、同一放电方向相减：第 100 圈与第 10 圈的放电容量曲线，在公共电压栅格上逐点作差。

- **物理含义**：老化导致的容量损失在电压轴上的分布。锂库存损失（LLI）让曲线整体下移，活性材料损失（LAM）让特定电压段的谷变深。
- **量级**：恒为负，约 −0.4 ~ 0 Ah。长寿命电池前 100 圈衰减小，ΔQ 只有几 mAh；短寿命电池可达上百 mAh。
- **为什么稳**：只关心「容量少了多少、少在哪个电压段」，与充电协议关系弱。

数据直接取数据集自带的 `Qdlin`（Vdlin 3.5→2.0 V，1000 点），重采样到 2.0–3.5 V / 300 点栅格。**不要从原始 V/I 自积分**：3.4–3.5 V 陡降段对噪声极敏感，插值稍有不稳整条曲线就会偏移——本项目实测过，同一循环在 3.3 V 处的容量会从 11 mAh 偏到 1.06 Ah，方向直接反过来。

### 2.2 滞回口径（作为对照特征保留）

$$\Delta Q_{\text{hys}}(V) = Q_{\text{discharge}}(V) - Q_{\text{charge}}(V)$$

同一循环内、充放电两个方向相减，反映库仑效率损失与极化滞后。

- 量级 0–350 mAh，比论文口径大两个数量级；
- **对充电协议高度敏感**：batch3 换了快充策略，滞回形状直接变，特征整体漂移；
- 仍含寿命信息（极化上升与老化相关），但回答的不是论文那个问题。

实现上必须先对齐容量起点——放电容量从高压端累积、充电容量从低压端累积，直接相减会得到 ±700 mAh 的伪特征：

```python
Q_discharge = Q_discharge[0] - Q_discharge   # 换算成自低压端起算
```

### 2.3 为什么必须把两者分开

同一批数据、同一个官方划分，只换特征口径：

| 特征口径 | 主测试 43 颗 | batch3 40 颗 | 跨批次退化 |
|---|---|---|---|
| 论文 ΔQ(V)（6 维，GBM） | 8.58% | **8.03%** | −6% |
| 全部特征（60 维，GBM） | **6.20%** | 16.37% | +164% |

滞回特征在**同分布**下有额外信息（6.20% < 8.58%），但**跨批次**是噪声源。特征维度不是越多越好，关键是维度里有没有编码「环境」而不只是「电池」。

## 三、RUL：两组特征，两套口径

### 3.1 全部特征（60 维）

| 组 | 内容 | 维度 |
|---|---|---|
| 论文 ΔQ(V) | `xq_log_var` / `xq_log_min` / `xq_log_mean` | 3 |
| 滞回统计 | 第 2 圈 / 第 100 圈 / 两者差值的 min、var、log\|min\|、mean | 12 |
| 滞回定点 | 3.0 / 3.2 / 3.4 / 3.5 V 处的容量差 | 12 |
| 老化标量 | 容量（2/100 圈、比值、斜率、截距、标准差）、内阻（2/100 圈、比值、斜率）、充电时间、温度、库仑效率 | 18 |
| 充电策略 | 15 维快充协议参数 | 15 |

### 3.2 论文 6 特征（对标用）

| 特征 | 数学 | 与 log₁₀(寿命) 的相关系数 |
|---|---|---|
| `xq_log_var` | log₁₀ Var(ΔQ) | **−0.927** |
| `xq_log_min` | log₁₀ \|min ΔQ\| | −0.922 |
| `xq_log_mean` | log₁₀ \|mean ΔQ\| | −0.911 |
| `qd_slope` | 第 2–100 圈容量线性拟合斜率 | +0.402 |
| `qd_intercept` | 同上，截距 | −0.122 |
| `qd_2` | 第 2 圈放电容量 | −0.061 |

三个形状特征的 |r| 都在 0.91 以上，三个趋势特征都不到 0.4——**模型自己会学出「形状 >> 容量」**，与论文结论一致。

实现见 `src/rul/features.py`：`build_features(...)` → `feature_sets()` 返回 `{"full": 60, "paper6": 6}` 两套列名，可直接做消融。

**为什么保留「差值」类特征**：不同电池的初始 ΔQ 水平差异很大（批次、化成），**第 100 圈相对第 2 圈的抬升量**才是纯老化信号。

## 四、模型与超参

所有模型都走同一条流水线：`中位数填补 → （标准化）→ 回归器`，目标取 `log(cycle_life)`。

| 模型 | 关键超参 |
|---|---|
| ElasticNet | `alpha` 由训练集内 5 折 CV 选取（全特征 0.01 / 论文 6 特征 0.003），`l1_ratio=0.5`, `max_iter=50000` |
| RandomForest | `n_estimators=400`, `max_depth=None`, `min_samples_leaf=1` |
| GradientBoosting | `n_estimators=300`, `learning_rate=0.03`, `max_depth=2`, `subsample=0.9` |
| MLP | `hidden=(64, 32)`, `alpha=3.0`, `lr=3e-3`, `max_iter=4000` |
| 1D CNN | 3 通道（第 2 圈滞回 / 第 100 圈滞回 / 两者差）+ 标量分支；5 折内部 CV + 早停 + 折模型集成 |
| 常数中位数 | 基线：永远预测训练集中位数 |

**为什么 GBM 用 `max_depth=2`**：41 颗训练电池，深树会直接记住个体。浅树 + 小学习率 + 300 轮是刻意选的保守配置。

**为什么 CNN 要内部 CV**：41 颗电池上单次划分的方差极大，固定 epoch 训练会退化成「向均值收缩」（首版 32.87%）。改成 5 折内部 CV + 早停 + 折模型集成后到 32.67%——依然明显落后于树模型，但这已经是这批数据能给出的水平。

## 五、评估协议

| 项 | 设置 |
|---|---|
| 数据划分 | 官方 41 / 43 / 40，按电池分组，**无循环级泄漏** |
| 输入 | 每颗电池前 100 圈 |
| 主指标 | 中位相对误差 median APE |
| 辅助指标 | 平均 APE、RMSE（圈）、R² |
| 补充协议 | 全量 124 颗 5 折交叉验证（`KFold`，按电池划分） |
| 随机种子 | 42（固定） |
| 预测截断 | `clip(pred, 50, 3000)`，仅用于指标与绘图，防止个别极端值把 RMSE 拉爆 |

**为什么主指标用中位数而不是平均**：寿命跨度 148–2237 圈，少数离群电池会让平均 APE 失去意义（例如 ElasticNet 中位 7.77% 但平均 21.27%）。中位数更接近「典型电池的表现」，也与 Severson 2019 的口径一致。

## 六、物理仿真

用 PyBaMM 做机理层验证。三个模型按保真度排列：**DFN**（全阶，含电解液输运，作参照）、**SPM**（单粒子，忽略电解液）、**Thevenin**（一阶 RC，即第一节的 ECM）。

| 项 | 设置 |
|---|---|
| 参数集 | `Prada2013`（A123 2.3 Ah LFP/石墨，与 MIT 数据同化学体系）；对照用 `Chen2020`、`OKane2022` |
| 电压窗口 | LFP 2.0–3.5 V；NMC 3.0–4.2 V；OKane2022 2.5–4.2 V |
| 退化机制 | SEI：`solvent-diffusion limited`；析锂：`irreversible`（仅 OKane2022 支持） |
| 退化模式注入 | LLI 改负极初始锂浓度；LAM_pos / LAM_neg 改对应电极活性材料体积分数 |
| ΔQ(V) 口径 | 与 MIT 一致，仿真输出插值到 300 点公共栅格后做跨循环差 |
| t80 | 充到 80% 荷电量的时长，**不含恒压段**（与 Severson 口径一致） |

四个必须做对的工程点（都是踩坑换来的）：

1. **额定容量 ≠ 可用容量**。`Prada2013` 额定 2.3 Ah，1C 实放只有 1.94 Ah。按额定容量折算充电时长会触发
   `Experiment is infeasible`，必须用实测容量折算（`capacity_scale()`）。
2. **每一段恒流都要带电压上限**。老化后容量下降，全程按时长充电必然过充；更要紧的是激进协议
   在给定电芯上根本执行不完——`6C(60%)` 在 5 Ah NMC 上从空电充，端电压第 5.4 min 前就冲到 4.68 V，
   下一步直接 `EmptySolution`。所有恒流段都写 `Charge at X C for N minutes or until 3.5 V`，
   这也正是真实充电器的行为。被截断多少，本身就是结论。
3. **SEI 参数要借**。`Prada2013` 不含 SEI 参数，从 `Chen2020` 补齐（SEI 本征量与正极化学无关，物理上成立），
   并把溶剂扩散系数放大 1000 倍才能落到真实寿命量级。
4. **Thevenin 的 OCV 要转成插值符号**。`Open-circuit voltage [V]` 在符号代入阶段是 `pybamm.Symbol`，
   不能 `float()`，必须用 `pybamm.Interpolant`；数值输入时才走 `np.interp`。

仿真只用于**比较协议之间的相对差异**，绝对量级不可信——见 [sim.md](sim.md) 的局限一节。
针对第三方 P3 辨识的审计与三线合并见 [audit.md](audit.md)。
