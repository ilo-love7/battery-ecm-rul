## 三、分阶段任务与验收标准（全部可量化验证）

### 阶段 0：环境与数据获取（第 1 周前半）
**任务**：注册 Kaggle/Colab；建 Git 仓库（建议 GitHub 私库）；下载 NASA 数据集并成功解析一份 .mat 文件；确定 MIT 数据下载方式。
**验收标准**：
1. 仓库中可运行 `environment.yml`/`requirements.txt` 一键装环境；
2. Notebook 成功绘出 NASA 任一电池单次充放电电压-时间曲线（图入仓即验收）；
3. MIT 数据集启动下载并确认完整性（文件数/大小核对）。
**补充（采纳严谨建议）**：MIT 数据下载完成当周即做一次 **md5 全量校验并记录归档**（结果写入 `data_check.md`），避免第 2 周才发现损坏返工。

### 阶段 A：ECM 参数辨识（P3，第 1-2 周）
**任务**：实现 1 阶与 2 阶 RC 等效电路；对 NASA 至少 2 颗电池、3 种 SOC 工况做脉冲响应参数辨识；对比模型输出与实测电压。
**验收标准**：
1. 参数辨识结果表（R0/R1/C1/R2/C2 随 SOC 变化）入仓；
2. 模型拟合电压 RMSE ≤ 实测量程的 2%（同工况复测）；
3. 一份对比图：实测 vs 1阶 vs 2阶模型端电压曲线；
4. 2 页阶段小结（方法-结果-结论）。

### 阶段 B：数据统一预处理（第 2-3 周）★ P1 第一里程碑
**任务**：编写统一解析模块，将 NASA/CALCE/MIT 三套异构数据转成统一格式（每循环：容量曲线、充电曲线片段、温度）；建立数据质量检查。
**验收标准**：
1. 一键预处理脚本：输入原始数据 → 输出统一 HDF5/Parquet；
2. **下载完整性校验（采纳严谨建议）：记录各数据集文件大小/md5 清单 + 循环数抽查（抽样 ≥3 颗电池核对循环数与官方/论文口径一致），校验结果写入 `data_check.md` 入仓**；
3. 循环级数据表含：电池编号、循环号、放电容量、SOH 标签，行数与数据集官方循环数一致（误差 <1%）；
4. 数据质量报告：缺失/异常循环清单及剔除规则说明。
**参考实现**：Severson 官方数据加载仓库 https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation （博远已验证可访问，含数据读取与预处理示例）。

### 阶段 C：RUL 预测建模（第 3-5 周）
**任务**：特征工程（ΔQ(V) 曲线特征 + 容量衰减统计特征）；先基线模型（线性回归/随机森林），后深度模型（CNN-LSTM）；80/20 训练测试划分遵循 Severson 协议（按电池分组，不泄漏）。
**验收标准**：
1. MIT 数据集测试集循环寿命预测误差：测试电池 RMSE 与基准论文同量级（目标：相对误差中位数 ≤ 10%），并在报告中注明与 Severson 2019 数值的对比；
2. 至少 2 类模型（经典 ML + 深度）横向对比表；
3. 训练代码含随机种子固定，结果可复现（重跑一次误差波动 <5%）；
4. 预测 vs 真实散点图 + 误差分布图入仓。

### 阶段 D：创新延伸（第 5-6 周，可选，由林工届时确认）
- 备选 D1：NASA/CALCE 数据上做零样本/少样本泛化，量化跨数据集性能下降；
- 备选 D2：PyBaMM 生成仿真老化数据做训练增强（博远届时补 PyBaMM 相关文献）。
**验收标准**：产出对照实验表（基准 vs 增强），如提升 ≥5% 即形成论文/报告创新点段落初稿。

### 阶段 E：数据小工具 P7（第 3-5 周，与 C 并行）
**任务**：Streamlit 应用：上传/选择数据集 → 自动解析 → SOH 衰减曲线 + 容量分布图 + 简单寿命初筛。
**验收标准**：
1. 应用可对三套数据各至少 1 颗电池完成端到端展示；
2. 部署到 Streamlit Cloud 并给出公开访问链接；
3. 响应时间：单电池解析+绘图 ≤ 10 秒。

### 阶段 F：总结交付（第 6-7 周）
**任务**：项目报告（背景-方法-结果-结论）、演示文稿、代码仓库 README 整理。
**验收标准**：
1. 报告 8-15 页，含全部验收图表；
2. README 使第三方可按步骤复现主结果；
3. 严谨完成数据/引用/结论一致性审查并出具核查意见。
