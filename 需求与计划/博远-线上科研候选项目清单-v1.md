## 一、候选项目清单（7 项）

### P1. 锂电池剩余寿命（RUL）预测 —— 复现型 ★★☆☆☆
- **内容**：基于 MIT-Stanford 124 颗磷酸铁锂/石墨电池快充循环数据集（Severson et al., Nature Energy 2019，被引 3800+），提取充电曲线特征（ΔQ(V) 等），用机器学习/深度学习预测循环寿命。可扩展 NASA 与 CALCE 数据做跨数据集泛化（创新型延伸点）。
- **数据**：MIT-Stanford 数据集：★ https://data.matr.io/1 （Kaggle 亦有镜像，检索 "MIT-Stanford Dataset"）；NASA PCoE 电池数据集直链：★ https://phm-datasets.s3.amazonaws.com/NASA/5.+Battery+Data+Set.zip ；CALCE 数据：★ https://calce.umd.edu （页面 "Battery Research Data"）
- **开源基准**：已检索到多个公开复现仓库（如 CNN-LSTM 多通道充电曲线 RUL 预测）；另有 2024 年开放获取论文提供"数据集+代码库+深度学习基准"三件套（Wang et al., 2024, ScienceDirect）。
- **算力**：Colab 免费 GPU 足够；数据集 < 10 GB。
- **复现条件**：Python 生态即可；无实验设备需求。

### P2. PyBaMM 锂电池物理仿真 —— 复现+创新型 ★★☆☆☆
- **内容**：用开源电池仿真包 PyBaMM 实现等效电路/单粒子/DFN（Doyle-Fuller-Newman）模型的充放电模拟、快充协议对比与老化仿真。复现基准曲线后，可创新型研究"快充策略-发热-寿命"耦合（贴合 Severson 数据集的快充主题）。
- **工具**：★ https://pybamm.org ｜ ★ https://github.com/pybamm-team/PyBaMM ｜ 文档：★ https://docs.pybamm.org
- **文献**：Sulzer et al., "Python Battery Mathematical Modelling (PyBaMM)", JOSS 2021（被引 686，检索确认）。
- **算力**：纯 CPU 即可，笔记本/Colab 均可；无外部数据依赖。
- **复现条件**：pip 安装即用，文档成熟，是最容易出"可演示结果"的方向。

### P3. 电池等效电路模型（ECM）参数辨识 —— 复现型 ★☆☆☆☆
- **内容**：搭建 1-2 阶 RC 等效电路，用公开充放电曲线（NASA/CALCE）以最小二乘/优化方法辨识 R0、R1、C1 等参数，模拟不同 SOC/温度/倍率下的电压响应，评估模型精度。工作量最小、最快出图出结论。
- **数据**：同 P1 的 NASA/CALCE 数据集。
- **工具**：SciPy（least_squares）、NumPy、Matplotlib；无额外依赖。
- **算力**：CPU 即可。
- **复现条件**：与定安提出的方案一致，文献与数据基础充分，适合作为入门首项目或与 P1 组合。

### P4. 基于 Materials Project 的电池/正极材料机器学习预测 —— 创新型 ★★★☆☆
- **内容**：通过 Materials Project 开放数据库 API 拉取材料形成能/带隙/电压数据，用成分特征或图神经网络（CGCNN，Xie & Grossman 2018，检索确认）预测候选正极材料性质，做成分筛选。AI for Science 属性强，上限高。
- **API 可用性核查结论**（林工指定核查项）：★ https://docs.materialsproject.org 可访问（200），文档完整；★ https://api.materialsproject.org 服务在线（未带密钥返回 403，属预期行为）——**需免费注册获取 API Key**，学术用途免费。配套 Python 库为 mp-api + pymatgen（pymatgen 的 Battery 模块在 matsci.org 论坛有官方使用指南，检索确认）。
- **算力**：成分特征模型 CPU 即可；CGCNN 需 Colab/Kaggle GPU，门槛可控。
- **复现条件**：需要一定材料学背景与图神经网络经验；数据获取依赖 API 配额。

### P5. 半导体器件漂移扩散方程数值仿真 —— 创新型（偏编程/数理）★★★☆☆
- **内容**：数值求解泊松方程 + 载流子连续性方程（漂移扩散模型），复现 PN 结/MOSFET 的 I-V 特性曲线。两条路线：① 直接使用 NIST 开源工具 Sesame（Python，有限差分，2D 漂移扩散泊松求解器）；② 用 FEniCS 有限元自行实现 Scharfetter-Gummel 离散化（后者数理挑战与创新性更高）。
- **开源工具**：★ https://github.com/usnistgov/sesame （美国国家标准与技术研究院官方仓库，可访问性已验证）；FEniCS 实现路线可参考官方论坛的 Scharfetter-Gummel 实现讨论帖（fenicsproject.discourse.group，检索确认）。
- **算力**：CPU 即可；无外部数据依赖。
- **复现条件**：需要 PDE 数值求解基础；调试周期比 P1-P3 长。

### P6. 交通/驾驶轨迹数据建模 —— 复现型 ★★☆☆☆
- **内容**：基于公开轨迹数据做跟驰模型（car-following）建模、轨迹预测或换道行为分析，可选做电动汽车能耗分析延伸。
- **数据**：NGSIM（美国 FHWA，US-101/Lankershim 路段高精度轨迹，data.gov 供下载，检索确认条目 "Next Generation Simulation (NGSIM) Vehicle Trajectories"）；highD 无人机采集数据集（Krajewski et al., 2018，被引 2271）：★ https://levelxdata.com/highd-dataset/ （16.5 小时、11 万车辆、45,000 公里）。
- **开源基准**：已检索到基于 NGSIM 的跟驰模型 ML/DL 公开复现仓库（GitHub，检索确认）。
- **算力**：CPU 即可（轨迹预测上深度模型时 Colab 免费 GPU 够用）。
- **复现条件**：数据为 CSV/文本格式，清洗工作量中等；领域（汽车/交通）与智诚指导范围匹配。

### P7. 电池科研数据处理与可视化小工具 —— 开发型 ★☆☆☆☆
- **内容**：开发"电池循环数据自动解析 + SOH 曲线可视化 + 寿命初筛"的 Web 小工具（Streamlit/Gradio 一页部署），统一解析 NASA/CALCE/MIT 格式。见效最快，可直接写进简历，也可作为 P1/P3 的配套交付物。
- **数据/工具**：复用 P1 数据源；Streamlit、Pandas、Plotly。
- **算力**：CPU 即可，可免费部署（Streamlit Cloud）。
- **复现条件**：纯开发，无文献依赖风险；验收标准容易量化。

## 三、可行性结论与组合建议（供林工决策参考）

1. **稳妥组合（首选）**：P3（ECM 参数辨识，1-2 周出成果）→ P1（RUL 预测，对标 Nature Energy 2019 基准）。"物理建模 + 数据驱动"形成完整叙事，全部数据/代码公开，复现风险最低。
2. **上限组合（创新型）**：P2（PyBaMM 仿真）与 P1 结合——用 PyBaMM 生成仿真老化数据并与真实数据集对比，探索"仿真增强的寿命预测"，具备论文创新点潜力。
3. **交叉方向（若想扩领域）**：P4（材料筛选）上限最高但周期与背景要求也最高；P6 适合汽车工程兴趣者。
4. 林工提出的四个预判方向核查结果：① 电池 SOC/SOH/RUL —— **证据充分，建议立项**；② 半导体简化仿真 —— 可行，工具链成熟（NIST Sesame），但调试周期长；③ 交通数据建模 —— 可行，数据与基准均公开；④ 小工具开发 —— 可行，建议作为 ① 的配套交付而非独立立项。
