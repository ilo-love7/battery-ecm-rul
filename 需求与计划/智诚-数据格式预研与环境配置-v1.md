## 二、三套数据集格式差异对照（阶段 B 核心依据）

| 维度 | NASA PCoE | MIT-Stanford (Severson 2019) | CALCE |
|---|---|---|---|
| 文件格式 | .mat（MATLAB v7，每颗电池一文件） | .mat（batch1~4 打包，数 GB） | .xlsx 为主（部分提供 .mat） |
| 解析工具 | `scipy.io.loadmat` | `scipy.io.loadmat` + 官方加载脚本 | `pandas.read_excel` / openpyxl |
| 内部结构 | batch → battery → cycle{charge/discharge/impedance} 三类交替 | 与 NASA 同源（Arbin 采集），字段命名相似但 batch 组织不同 | 表格列式（Voltage/Current/Temperature/Time） |
| 循环口径 | 放电容量以**参考放电**为准；阻抗测量循环需剔除 | 循环数多（每电池 ~150-1000+）；含交织的 rest/标定循环 | 逐次记录，CS2/CX2 系列命名区分批次 |
| 已知坑【文献】 | 部分批次末尾存在损坏/异常条目，需在预处理中按官方论文口径做剔除规则（严谨/定安的"循环数抽查"即针对此项） | 部分电池实验中止、个别电池循环计数与论文表格需核对；数据量大，loadmat 内存占用高（建议逐 batch 处理） | xlsx 读取慢（pandas+openpyxl），建议一次性转 Parquet 后续只读 Parquet |
| 许可要求 | 公开，引用 PCoE | 公开，引用 Severson 2019 + Attia 2020 | 公开但**必须引用原始论文**（计划风险表已列） |
| 体量 | ≈200 MB【实测】 | 数 GB【文献】，首周后台下载 + md5 校验（已定案） | 单文件小，总量 <1 GB |

### 统一化建议（直接可写入阶段 B 设计）
目标 schema（与定安计划一致，Parquet 存储，两级表）：
1. **cycles 表**（逐循环曲线段）：`cell_id, cycle_id, t[], V[], I[], T[]` → 支持 ECM 拟合（阶段 A）与 ΔQ(V) 特征（阶段 C）复用同一数据；
2. **summary 表**（逐循环标量）：`cell_id, cycle_id, discharge_capacity, SOH=cycle_cap/cycle1_cap, ambient_T` → 直接支撑 RUL 建模与小工具展示；
3. 解析器按数据源分三个模块（`parsers/nasa.py, mit.py, calce.py`），输出接口统一，避免阶段 B 脚本耦合。

### 与计划 v1.0 的兼容性结论
- 定安计划的数据口径（NASA/CALCE/MIT）与格式判断**无冲突**，无需修订；
- 唯一更新建议：NASA 体量由"<1 GB"细化为"≈200 MB【实测】"，下载窗口可压缩；
- 严谨的两级完整性校验方案可行，追加一点：**NASA/MIT 的 .mat 校验用文件级 md5 即可；CALCE xlsx 建议同时记录"表行数+循环数"双口径**，防止 Excel 文件被表格软件重写后 md5 变化造成误报。

## 三、其他预研补充（对应博远此前提问）

1. **P4（储备）mp-api 注册流程**：materialsproject.org → 注册账号 → Dashboard 获取 API Key → `pip install mp-api` → `MPRester("你的Key")`。学术免费、有每日请求配额，特征级筛选够用。本环境安装验证进行中（依赖较重，属正常）。
2. **P5（储备）NIST Sesame 上手成本**：纯 Python、有限差分 2D 漂移扩散求解器，`pip install -e` 源码安装即可；主要成本在 PDE 数值调试（收敛性/网格），属阶段型储备，不在本主线投入。
3. **PyBaMM（阶段 D）**：安装正常但含编译依赖，建议阶段 D 启动时在 Colab 上安装（官方文档提供一键环境），本机不必预装。

## 四、给执行层的操作指引（阶段 0 开工即可用）

1. 第 1 周后台下载顺序：NASA zip（200 MB，几分钟）→ CALCE（按需逐电池）→ MIT（数 GB，后台挂起，完成后立即 md5 归档）；

3. 不要在阶段 0 提前装 torch/pybamm 等重依赖，主线环境保持轻量，避免 Colab 免费档内存浪费。
